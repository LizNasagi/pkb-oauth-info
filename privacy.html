PKB プライバシーポリシー

対象と利用目的

本方針は、個人用アプリケーションPKBによるGoogle連携と、本アプリの公開案内ページを対象とします。

PKBは、本人が指定した受付表に含まれるメモ・支出等の記録、出典、更新情報と、保存先ファイルの情報を扱います。これらを、受付、検証、保存、履歴管理、重複確認、検索、照合、バックアップ、復旧と、本人向けの状態配信に使用します。

Googleから求める権限

  • spreadsheets.readonly：Google Sheetsの内容を読み取るために使用します。この権限はGoogle側ではアカウントのスプレッドシートの読取権限です。PKBの通常処理は、あらかじめ設定した受付表と範囲を対象にします。
  • drive.file：アプリが作成したファイル、または本人がアプリによる利用を許可したファイルを扱うために使用します。Googleの同意画面では参照・編集・作成・削除を含む権限として表示されます。PKBでは、承認された記録の保存、指定台帳の更新、本人向け配信等のために使用します。

権限は用途ごとに分けて管理し、同じclientであっても、読取と書込の認可・実行記録を別に保持します。

保存、共有、保護

記録と履歴は本人のPC上の私有領域、および本人が設定したGoogle上の保存先へ保存します。認証情報はローカルの私有領域で管理し、公開案内ページや公開リポジトリには含めません。

取得したGoogleユーザーデータを、広告、販売、信用判定の目的には利用しません。公開案内ページには、本人のGoogle上の記録、認証情報、ローカルの保存場所を掲載しません。本人がAIサービス等を入口に選んで情報を入力する場合、そのサービスによる処理には当該サービスの方針も適用されます。

PKBは、Google API Services User Data PolicyのLimited Use要件を含む要件に従って、Google APIから取得した情報を使用します。

保持と利用停止

記録、原文、履歴、認証や失敗の証拠は、本人の保管・照合・復旧のために保持します。利用停止や認証失効を理由として自動消去しません。本人はGoogleアカウントの接続済みアプリ管理から認可を撤回でき、PC上の自動処理も停止できます。保存済み記録の整理は、原本や履歴への影響を確認して本人が行います。

公開案内ページの通信情報

GitHub Pagesを公開先として採用した場合、ページへのアクセス時には、GitHubがセキュリティ目的で訪問者のIPアドレスを記録します。案内ページには、独自のアクセス解析、広告、入力フォームを設けません。GitHubによる処理にはGitHub Privacy Statementが適用されます。

変更と連絡先

扱うデータ、目的、共有方法を変更するときは本方針を更新し、必要な追加の同意を受けてから変更します。連絡先はGoogle OAuth同意画面のユーザーサポートメールです。
